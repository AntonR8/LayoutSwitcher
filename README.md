# LayoutSwitcher

Бесплатный переключатель раскладки для macOS. Открытый код, ~370 строк Swift, без зависимостей.

Перебивает текст, набранный не в той раскладке. Набрал `ghjdthrf` — двойной Shift, получилось `проверка`.

Нажми Shift ещё раз, и охват расширится: слово → предложение → с последней смены раскладки → вся строка. Пауза в 2 секунды сбрасывает цепочку. Если охват уже перебит, повторный двойной Shift вернёт как было.

Живёт в строке меню, иконки в Dock нет.

---

## Установка

**1.** Перетащи `LayoutSwitcher.app` в папку «Программы».

**2.** Сними карантин — иначе macOS не даст запустить. Сборка не нотаризована
(нотаризация требует платного членства в Apple Developer Program), поэтому
Gatekeeper блокирует её по умолчанию:

```
xattr -dr com.apple.quarantine /Applications/LayoutSwitcher.app
```

**3.** Запусти. Появится запрос доступа к клавиатуре.

**4.** Настройки → Конфиденциальность и безопасность → **Универсальный доступ** → добавь `LayoutSwitcher` и включи переключатель. Перезапускать не нужно, программа подхватит разрешение сама (значок в панели сменится с треугольника на обычный).

**5.** В меню значка включи «Запускать при входе», если нужно.

## Почему требуется доступ к клавиатуре

Чтобы перебить последнее слово, программа должна знать, какие клавиши ты нажал. Она ставит перехватчик событий (`CGEventTap` в режиме «только слушать») и держит последние 512 нажатий в оперативной памяти.

**Это тот же уровень доступа, что у кейлоггера.** Так что честно:

- Программа **никуда ничего не отправляет** — сетевого кода в ней нет вообще.
- **Ничего не пишет на диск.** Буфер живёт только в памяти и сбрасывается на Enter, Tab, стрелках, клике мышью и сочетаниях с Cmd/Ctrl/Option.
- Хранятся не символы, а скан-коды клавиш — нужны, чтобы заново истолковать их в другой раскладке.

Проверить всё это можно по исходникам, их тут ~370 строк. `Sources/main.swift` — весь код целиком.

Если не доверяешь готовому бинарнику — собери сам, см. ниже. Это правильная реакция на программу, которая просит такой доступ.

## Сборка из исходников

Нужен Xcode или Command Line Tools (`xcode-select --install`).

```
./build.sh          # собрать в build/LayoutSwitcher.app
./test.sh           # прогнать тесты логики границ
```

Подпись в `build.sh` берётся из переменной `SIGN_ID`. Если своего сертификата нет, скрипт сам откатится на ad-hoc — работать будет, но выданный доступ к Универсальному доступу придётся выдавать заново после каждой пересборки.

Значок в строке меню — одна константа `symbolName` в `Sources/main.swift`, любое имя из SF Symbols.

## Известные ограничения

- Нет автоматического режима: программа не угадывает ошибку сама, перебивает только по двойному Shift.
- Работает с двумя раскладками — латинской и нелатинской. Если включено три и больше, парную выбирает первую подходящую.
- Не трогает выделенный текст, только последний набранный.
